# 情绪趋势

本文件记录每日情绪评估结果，用于追踪情绪的中长期趋势。

**写入规则**：
- 每日晚间总结（daily-review）时由情绪教练（emotion-coach）自动追加
- 不需要用户逐条确认（属于工作记忆层）
- 但情绪教练给出的个性化评价本身是自动生成的，不直接写入此处
- 此处只记录客观的情绪信号评估结果

---

## 每日记录格式

```markdown
### YYYY-MM-DD 情绪评估
- **主要情绪**：[焦虑/兴奋/疲惫/平静/满足/纠结/中性]
- **信号来源**：[今日碎碎念中的情绪线索简述]
- **强度**：[低/中/高]
- **备注**：[特别观察，如与某事件相关]
```

## 使用说明

### 这个文件怎么用

- **情绪教练读取**：每晚总结时读取近期记录，判断趋势（本周比上周更焦虑还是更平静）
- **惊奇度扫描读取**：检测情绪模式变化（比如「连续三天高强度焦虑」可能是善意提醒的信号）
- **用户可随时查看**：直接打开本文件了解自己的情绪变化轨迹

### 和其他文件的关系

- `MEMORY.md` 情绪趋势区块：一句话概括本周基调，指向本文件
- 情绪教练 Skill：读取本文件的历史数据 + 写入当日评估
- 善意提醒：连续多天的负面情绪信号可能触发温和提醒
