# 偏好记忆

本文件记录关于用户「怎么想」和「在意什么」的稳定偏好。

**写入规则**：
- 只有晚间惊奇度扫描发现的高惊奇信号才会被提议写入此处
- 写入前需用户确认
- 条目采用统一格式（见下方）
- 强度规则：★ 初始观察 / ★★ 重复验证 / ★★★ 稳定模式

**索引关联**：每条写入完成后，同步更新 MEMORY.md 索引文件的对应条目。
